# plan_FileService —— 完整文件服务（上传 + 鉴权）

## 0. 背景与风险

trynet 现在用 `http.FileServer` 提供只读的目录分享。这次要加上传，同时加鉴权。

**风险性质变了**：只读时最坏情况是"别人读到我的文件"；有了上传就是
**"别人往我硬盘里写文件"**，而且通道是公网可达的隧道。鉴权从锦上添花变成
唯一的那道门，实现质量必须较真。

## 1. 功能范围

**做**：目录列表、下载、上传（浏览器可用的极简页面 + 表单）。

**不做**：删除、重命名、新建目录、在线预览、分片续传。那是文件管理器，
不是这次要的东西。需要了再说。

## 2. 参数

| 参数 | 环境变量 | 默认 | 说明 |
| --- | --- | --- | --- |
| `-upload` | `TRYNET_UPLOAD` | false | 开启上传。往磁盘写东西应该显式开启 |
| `-no-auth` | `TRYNET_NO_AUTH` | false | 关掉鉴权，回到纯公开只读 |
| `-user` | `TRYNET_USER` | `admin` | 登录用户名 |
| `-pass` | `TRYNET_PASS` | 随机生成 | 登录密码，不给就随机 8 位 |

鉴权**默认开启**，覆盖整个服务（列表、下载、上传都要过），不是只保护上传口。

## 3. 安全要求（这一节是这个功能的核心，不是附注）

### 3.1 路径穿越

上传文件名是攻击面最大的地方。`../../../.ssh/authorized_keys`、
`..\..\windows\system32\...`、URL 编码变体、多重编码、绝对路径，
全部必须挡住。

做法：
- 只取 `filepath.Base(name)`，丢掉任何目录成分
- 再 `filepath.Clean`，然后确认最终绝对路径**仍在分享目录之内**
  （用 `filepath.Rel` 判断，不要用字符串前缀匹配——`/data` 和 `/data-evil`
  会让前缀匹配误判）
- 空文件名、`.`、`..`、以点开头的名字一律拒绝

### 3.2 密码比较

必须用 `crypto/subtle.ConstantTimeCompare`，**不能用 `==`**。
用户名和密码都要，而且两者都比较完再返回结果，不能比到用户名不对就提前返回——
否则能从响应时间逐字节试出密码。

### 3.3 密码生成

`crypto/rand`，不是 `math/rand`。字母表去掉易混字符（`0O1lI`），
因为用户要手敲。8 位 × 约 50 个字符 ≈ 45 bits，对一条临时隧道够用。

### 3.4 其它

- 上传**不覆盖**已有文件：同名时加后缀（`a.txt` → `a (1).txt`）
- 单文件大小上限（默认 100 MB，用 `http.MaxBytesReader`）
- 上传的文件名同样不能以点开头（和现有的点文件拦截规则一致）
- 鉴权失败返回 401 + `WWW-Authenticate`，不泄漏"用户名对了密码错了"这种信息

## 4. 输出

启动时在现有 `serving ... · via ...` 那行之后多一行（鉴权开启时）：

```
  login  admin / Kf7mQ2xR
```

上传开启时在这行后面标一下，比如 `  upload enabled`。
保持项目"行就行不啰嗦"的风格，不要多余的说明文字。

## 5. 实现位置

新建 `fileserver.go`：目录列表 + 下载 + 上传的 handler、以及鉴权中间件。
现有 `startFileServer` 从 `main.go` 移过来一起收拾。
点文件拦截逻辑也归并进来（现在散在别处）。

测试放 `fileserver_test.go`。

## 6. 测试要求

安全相关的测试是重点，必须扎实：

- **路径穿越**：`../x`、`..\x`、`%2e%2e%2fx`、`....//x`、绝对路径、
  嵌套 `a/../../b`，全部断言被拒且**文件没有被写到分享目录外**
  （测试要真去检查外面的路径没多出文件，不能只看返回码）
- **鉴权**：无凭据 401、错用户名 401、错密码 401、正确凭据 200；
  `-no-auth` 时无凭据也能访问
- **常量时间比较**：断言用的是 `subtle.ConstantTimeCompare`
  （可以测"用户名错但密码对"和"用户名对但密码错"都返回同样的结果）
- **不覆盖**：上传同名文件，断言原文件内容没变、新文件改了名
- **大小上限**：超限请求被拒
- **点文件**：上传 `.bashrc` 被拒；下载 `.git/config` 被拒（现有行为不能退化）
- 现有 82 个测试必须全部照常通过
